Computer Networks — Midterm Cheat Sheet (Ch. 1–5)

Dordal, An Introduction to Computer Networks · all exam questions = textbook exercises · neighbor form next_hop = name the neighbor, not the port number.

Ch. 1 · Datagram Forwarding

Switch/router forwards each packet using a forwarding table: rows ⟨destination, next_hop⟩. Directly attached = direct/local.

Flooding = out all ports except arrival (used when destination unknown / broadcast).

Build a table: for each dest, take the shortest path; next_hop = first switch on it. Ties → either is OK; indicate them.

Default entry ⟨default, next_hop⟩ catches unlisted dests. Delete explicit rows whose next_hop equals the default's next_hop (implied).

Routing loops: only two shapes — (1) two adjacent switches bounce a packet, or (2) a topological cycle. Linear loops of length > 1 impossible (forwarding is a function; a repeat traps the packet). Real defense: TTL (decrement/hop, drop at 0); split horizon / path vectors.

Weighted links: choose min total weight. Inverse problem ("make this route optimal"): weight 1 everywhere, one/two "bad" links weight 10.

Subnets: a Class C net 200.0.x/24 is one route row; direct nets = local, remote = neighbor router. (CIDR later.)

Ch. 2 · Ethernet Basics

CSMA/CD: listen first; transmit if idle; on collision send jam + back off.

Exponential backoff: after n-th collision choose k ∈ [0, 2ⁿ−1] slot times; retransmit at detect_time + k. n caps at 10 (1023); give up after 16 collisions.

Numbers: slot time = 512 bit-times = 51.2 µs; min frame = 64 B (guarantees collision detection); max payload = 1500 B.

Learning switch

  • Learn source addr → arrival port.
  • Dest known → forward that one port.
  • Dest unknown → flood; broadcast → flood.

Process frames in order; update every switch that sees the frame. A known destination stops the frame before downstream switches.

Loop w/o STP: unknown/broadcast frames have no TTL → flood forever (broadcast storm).

VLAN: logical color/ID per port; trunk frames tagged 802.1Q.

Ch. 3 · Advanced Ethernet

Spanning Tree (STP)

  • Root = lowest switch ID.
  • Each non-root: keep least-cost path to root; tie → lowest-ID neighbor.
  • Prune/block all other root-ward links → loop-free tree.
  • Switches exchange BPDUs.

Distance-vector for Ethernet

If switches can find directly-connected hosts, DV can build optimal tables even with loops; mark packets to test direct connectivity. Broadcast/multicast still loops.

SDN / OpenFlow

  • Switch = flow tables of match → action.
  • Unknown dest → report to controller; controller learns source (source → arrival port).
  • Switch then floods; if dest known → forward, no report.
  • Variants differ in the trigger: unknown dest only vs unknown dest or source.

Ch. 4 · Wireless LANs

Hidden node: two senders each reach a receiver but not each other → simultaneous tx collide at receiver. 3-sender: senders on a triangle/circle around receiver (or walls).

CSMA/CA (Wi-Fi): no collision detection; random backoff, DIFS > SIFS; ACK/CTS after SIFS; RTS/CTS for hidden nodes.

ACK without sensing: small, follows a just-finished tx; a "collision" only matters if a node reads neither signal.

Contention loss: 802.11g slot = 9 µs; 1 kB @ 54 Mbps ≈ 151 µs. Fraction of bandwidth lost = T_cont / (T_cont + T_tx). (avg 64 slots → 576 µs → ≈79 % lost.)

WiMAX/LTE: scheduled (base station allocates); subscribers needn't hear each other. Wi-Fi: listens & defers.

WiMAX ranging: 33 m/s over 60 s = 1980 m ⇒ 1980/300 ≈ 6.6 µs early/late; guard = 2× ⇒ 5000 senders/s ≈ 66 ms/s ≈ 6.6 %.

Two-ray ground: reflected path r′ ≈ r(1+2h²/r²); subtract 180°-shifted signals ⇒ amplitude ∝ 1/r² ⇒ power ∝ 1/r⁴.

Wi-Fi 4-way handshake: replay attack fails when AP sends a fresh nonce — replayed msgs carry the old nonce ⇒ wrong MIC.

Ch. 5 · Other LANs

VPN / tunneling

Private-addressed packets are encapsulated in Internet packets to a VPN gateway. Devices e.g. eth0 (public), ppp0 (tunnel).

  • "all else via ppp0" ⇒ traffic to a local/public addr is forced into the tunnel.
  • "all traffic via ppp0" ⇒ the tunnel's own packets get tunneled → recursion/loop.
  • Split tunnel must exclude the gateway address (and the carrier traffic).

Token Ring / Bus

Only the token holder transmits; avg passes over N stations = N/2. Order can be set by sorting numeric MAC addresses. Token 64 B @ 10 Mbps = 51.2 µs; ×20 = 1.024 ms.

ATM / AAL-5

Cell = 53 B (5 B header + 48 B payload). SM90: N cells + 1 XOR cell recovers any single loss. With XOR = 21 cells (no retx); without ≈ 20 + 400p. Equal at 21 = 20+400p ⇒ p = 0.25 %.

Virtual Circuits

VCI_inport_inVCI_outport_out
port = node at the other end; VCIs are per-link labels (reusable).

Trace a VC: start at ingress entry → follow VCI_out/port_out to next switch → match its VCI_in/port_in → repeat to endpoint. A switch visited twice has two rows (different incoming port).
